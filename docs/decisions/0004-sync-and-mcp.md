# 0004. Свой протокол синхронизации поверх Yjs, MCP SDK v2 по HTTP

- Статус: принято
- Дата: 2026-11-04

## Контекст

Нужна синхронизация досок между планшетом, маком и Windows с офлайн-правками, и доступ агентов к доскам.
Решение 0001 предполагало Hocuspocus. На момент спайка Hocuspocus перешёл на v4 с изменённым API,
а MCP TypeScript SDK — на v2 с новыми пакетами.

## Решение

**Синхронизация** — свой минимальный протокол (`packages/sync`) поверх Yjs и WebSocket:

- одно соединение — одна доска: `ws://хаб:4000/sync/<id>`;
- три сообщения: STEP1 (вектор состояния), STEP2 (недостающее), UPDATE (новое изменение);
- при подключении обе стороны шлют STEP1 — офлайн-правки доезжают в обе стороны без отдельной очереди;
- клиент переподключается сам, с нарастающей паузой до 10 секунд.

Это около 150 строк на стабильных API Yjs (`encodeStateVector`, `encodeStateAsUpdate`, `applyUpdate`).
Hocuspocus можно вернуть позже, если понадобятся его расширения (авторизация, вебхуки, масштабирование).

**Модель доски** (`packages/board`) — элементы в `Y.Map`, каждый элемент одним значением. Правки разных
элементов сливаются без конфликтов, одновременная правка одного элемента — «последний победил».

**Хаб** (`server/hub`) — Node: доски в памяти и на диске (`data/<id>.ydoc`), WebSocket-синк, REST, MCP.

**MCP** — SDK v2 (`@modelcontextprotocol/server`, `createMcpHandler`) по Streamable HTTP на `/mcp`.
По умолчанию эндпоинт принимает только запросы с этого компьютера (проверка Host и Origin).
Инструменты: `list_boards`, `read_board`, `add_sticky`, `search`. Правки агента помечаются
`createdBy.kind = 'agent'` и сразу приходят на подключённые устройства.

## Последствия

- Claude Code подключается локально: `claude mcp add --transport http kayospace http://localhost:4000/mcp`.
- ChatGPT и приложение Claude требуют публичный HTTPS-адрес с OAuth — это фаза 3 (хаб на VPS).
- Синхронизация пока без авторизации: хаб рассчитан на домашнюю сеть. Перед выходом в интернет — токены
  устройств и TLS (фаза 2).
