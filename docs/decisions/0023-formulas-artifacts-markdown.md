# 0023. Формулы в таблицах, артефакты Claude на доске, markdown без потерь

- Статус: принято
- Дата: 2026-11-05

## Контекст

Таблицам (решение 0021) не хватало формул. Кроме того, владелец работает в Claude: просит что-то сделать —
получает артефакт (страницу, рисунок, схему, код, документ) — и хочет быстро отправлять его на доску и так же
быстро забирать обратно в чат, чтобы продолжить. Для документов это значит работать с markdown без потерь:
Claude пишет обычный markdown с таблицами, картинками и вложенными списками.

## Решение

**Формулы** (`packages/page/src/formula.ts`, `table.ts`). Тип колонки «Формула»: значение считается для
каждой строки, в ячейках ничего не хранится — хранится только сама формула колонки (`Column.formula`).

- Синтаксис: `[Колонка]` (или просто имя без пробелов), числа с точкой, строки в кавычках, `+ - * / ^`,
  `&` — склейка строк, сравнения `= <> < > <= >=`, `ИСТИНА/ЛОЖЬ`; аргументы — через `;` или `,`.
- Функции (по-русски и по-английски): ЕСЛИ/IF, ОКРУГЛ/ROUND, ABS, СУММ/SUM, СРЗНАЧ/AVG, МИН/MIN,
  МАКС/MAX, СЧЁТ/COUNT, ДЛСТР/LEN, ПРОПИСН/UPPER, СТРОЧН/LOWER, СЦЕП/CONCAT, СЕГОДНЯ/TODAY, ДНИ/DAYS,
  И/AND, ИЛИ/OR, НЕ/NOT, ЕПУСТО/ISBLANK. `[Колонка]` внутри СУММ, СРЗНАЧ, МИН, МАКС и СЧЁТ — вся колонка.
- Формулы могут ссылаться на другие формулы; круг — ошибка с причиной. Ошибка в ячейке — «#ОШИБКА»,
  касание показывает причину. Значения считаются везде одинаково (`computeTable`): на экране, в итогах,
  сортировке, поиске, PDF, миниатюре и у агентов (`read_table` — значения и `formulaErrors`).
- В меню колонки: поле формулы (`CommitInput`) и кнопки-колонки, которые дописывают `[Колонка]`, —
  на планшете без клавиатуры квадратные скобки набирать неудобно.

**Артефакты** (`packages/page/src/artifact.ts`, `server/hub/src/mcp-artifacts.ts`, `ArtifactView.tsx`).
Ещё один вид документа рядом с досками, документами и таблицами: id `ar_…`, Map «artifact» — вид (`html`,
`svg`, `mermaid`, `code`), язык кода и исходник (`Y.Text`, заменяется целиком). Синхронизация, проекты,
удаление, корзина и история версий — общие.

- Агентам: `save_artifact` — сохранить или обновить по id (тот же id — новая версия на том же месте),
  сразу с карточкой на доске (`board`); `read_artifact` — исходник целиком. `place_doc`, `list_boards`
  (`kind: "artifact"`), `search`, `fetch` и `read_board` с `region` знают артефакты. В черновике ИИ
  в приложении — только `read_artifact`.
- На доске — карточка с меткой «Артефакт» и миниатюрой: SVG — сам рисунок, остальное — текст или код
  первой страницы. Касание открывает артефакт поверх доски живым: `iframe srcdoc` с
  `sandbox="allow-scripts allow-popups allow-forms allow-modals"` без `allow-same-origin` — скрипты
  и библиотеки с CDN работают, а к приложению, его хранилищу и токенам доступа нет. Mermaid рисуется
  библиотекой с jsDelivr (нужна сеть). Вид «Исходник», «Копировать», «Перезапустить».
- Правят артефакт в Claude, а не в приложении: так он остаётся тем же, что в чате.
- Экспорт: исходник файлом своего вида (`/api/export/ar_….src`: .html, .svg, .mmd, по языку кода) и PDF.

**«В Claude»** (`apps/workspace/src/claude.ts`). Кнопка в документе, таблице, артефакте и в меню выделенной
карточки открывает новый чат `https://claude.ai/new?q=…` с просьбой забрать этот документ с доски
(`read_page` / `read_table` / `read_artifact`) и показать артефактом; та же просьба — в буфере обмена.
Чат читает доску через коннектор Kayospace; обратно — «обнови на доске». Договорённости «на доску»,
«обнови на доске», «возьми с доски» записаны в инструкции агентам (`agent-guide.ts`) и в навыке для Claude.

**Markdown без потерь** (`packages/page/src/markdown.ts`, `schema.ts`).

- В документе появились таблицы (`@tiptap/extension-table`, правятся кнопками «+ строка», «+ колонка»,
  «− строка», «− колонка», «Убрать таблицу», пока курсор в таблице) и картинки (`@tiptap/extension-image`).
- Markdown ↔ страница: заголовки 1–6, вложенные списки (и чек-листы), нумерация с любого числа, язык
  у блока кода, таблицы (перенос строки в ячейке — `<br>`), картинки, ссылки и вложенные выделения.
  Разбор и запись проверены круговым тестом.
- `.md` — документом: кнопкой «Картинка, PDF или .md», перетаскиванием и «Поделиться» на Android.
  Название — из `title:` во фронтматтере, из первого заголовка или из имени файла; карточка ложится на
  доску. Документ — в `.md` из меню экспорта (открытый — с устройства, остальное — с хаба,
  `/api/export/pg_….md`).
- `write_page` с `mode: "section"` заменяет один раздел по заголовку (до следующего заголовка того же или
  более высокого уровня), остальное не трогает; раздела нет — добавляет его в конец.

## Последствия

- Зависимости: `@tiptap/extension-table` и `@tiptap/extension-image` — таблицы и картинки в документе
  делать своими силами долго, а схема TipTap общая для приложения и хаба.
- Карточка документа подписывается по id (`docCardLabel` в `model`) — одинаково на холсте и в картинке
  доски для агентов.
- Артефакт с CDN-библиотеками без сети не оживёт, но исходник и миниатюра видны всегда.
- Документы, сделанные до этого обновления, не меняются: в схеме только прибавились узлы.
