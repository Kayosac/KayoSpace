# 0011. Автообновление приложения

- Статус: принято
- Дата: 2026-11-05

## Контекст

Каждую новую версию приходилось скачивать из Actions и ставить руками на трёх платформах.

## Решение

**Компьютер (macOS, Windows)** — модуль обновлений Tauri (`tauri-plugin-updater`, перезапуск — `tauri-plugin-process`).

- Сборки подписываются ключом владельца (minisign). Закрытый ключ и пароль лежат в секретах репозитория
  `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`; открытый — в `tauri.conf.json`.
  Приложение ставит только то, что подписано этим ключом.
- Файлы обновления (`Kayospace.app.tar.gz`, `*-setup.exe` и подписи `.sig`) собираются только в CI и только
  при наличии ключа (`--config src-tauri/tauri.updater.conf.json`). Локальная сборка без ключа работает как раньше.
- Релиз по тегу `v*` публикует сборки и `latest.json` (`apps/app/scripts/latest-json.mjs`): версия, адреса
  и подписи для `darwin-aarch64`, `darwin-x86_64` (одна универсальная сборка) и `windows-x86_64`.
  Релиз — обычный, не предварительный: приложение читает `releases/latest/download/latest.json`.
- Приложение проверяет обновления через 5 секунд после запуска и раз в 6 часов; плашка «Доступна версия …» →
  «Установить» → загрузка с процентами → перезапуск. В настройках — «Проверить обновления».
  Windows ставит обновление в режиме `passive` (окно прогресса без вопросов).

**Android** заменить себя сам не может. Приложение сравнивает свою версию с последним релизом через API GitHub
(у него есть CORS) и предлагает «Скачать» — APK открывается в браузере, установку подтверждает система.

**Одна версия на всё приложение**: `apps/workspace`, `apps/app`, `tauri.conf.json` и `Cargo.toml` — одинаковые;
это проверяет тест (`updates.test.ts`).

## Последствия

- Выпустить версию: поднять версию в четырёх местах, слить, поставить тег `vX.Y.Z` — дальше всё делает CI.
- Потеря закрытого ключа = установленные приложения не примут новые версии; их придётся один раз
  переустановить вручную с новым ключом. Копия ключа — у владельца в надёжном месте.
- Android: APK подписан отладочным ключом сборщика CI, а он у каждого запуска свой. Поставить новую версию
  поверх старой Android не даст — нужен постоянный ключ подписи APK (следующий шаг, тоже в секретах).
- macOS без подписи Apple: обновления ставятся без вопросов, предупреждение Gatekeeper — только при первой установке.
