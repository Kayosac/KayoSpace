# 0002. Свой алгоритм отрисовки штрихов

- Статус: принято
- Дата: 2026-11-04

## Контекст

Изначально планировалась библиотека perfect-freehand. Для холста важны две вещи, которые проще получить своим кодом:
дорисовка активного штриха по кускам (чтобы каждый кадр перерисовывать только хвост) и полный контроль над тем,
как давление превращается в толщину.

## Решение

`packages/ink/src/render.ts`:

1. Сглаживание дрожи — экспоненциальное подтягивание точки к предыдущей (`streamline`).
2. Давление → радиус: `r = size/2 · (1 + thinning · (2p − 1))`. Без пера давление имитируется по скорости.
3. Кривая через середины соседних точек (квадратичные сплайны), разбитая на сэмплы с шагом 1,5 px.
4. Заливка — объединение «капсул»: круг в каждом сэмпле и касательная трапеция между соседями, все подконтуры
   одной ориентации, заливка nonzero. Нет дыр и артефактов на резких поворотах.

Построение причинное: выпущенные сэмплы не меняются. Активный штрих рисуется так: стабильная часть — один раз
на отдельный слой, хвост и предсказанные точки — заново каждый кадр.

## Последствия

- Нет внешних зависимостей в пакете пера.
- Стоимость кадра почти не зависит от длины штриха.
- Если понадобится полупрозрачный маркер, объединение капсул придётся рисовать в отдельный слой с последующим
  наложением с прозрачностью — сейчас все штрихи непрозрачные.
