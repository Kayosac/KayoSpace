# 0018. История версий, распознавание рукописного, OpenAI: картинки и голос

- Статус: принято
- Дата: 2026-11-05

## Контекст

Дальше по фазе 4 — история версий в интерфейсе и распознавание рукописного для поиска и агентов. Владелец
попросил ещё:

- «Вставь картинку» у ИИ в приложении — только найти в интернете, а рисовать — только на «нарисуй».
- Рисовать через OpenAI (как ChatGPT) — у Claude картинки выходят хуже.
- Голосовой ввод для ИИ в приложении.
- Фрейм страницы PDF чуть больше самой страницы, чтобы его удобно было брать.

Выбрано: всё внешнее — через один ключ OpenAI API на хабе.

## Решение

**«Вставь» и «нарисуй»** (`IMAGE_RULES` в `server/hub/src/ai.ts`). «Вставь / найди / добавь картинку» —
только готовая картинка из интернета (WebSearch → прямая ссылка → проверка WebFetch → `add_images` с `url`).
Не нашлась — ИИ ничего не рисует и так и отвечает. «Нарисуй / сгенерируй» — `generate_image`, если на хабе
есть ключ OpenAI, иначе Claude рисует SVG.

**OpenAI** (`server/hub/src/openai.ts`). Ключ — `OPENAI_API_KEY` в `deploy/.env`, только на хабе: устройствам
и агентам он не виден. Модели меняются переменными (`OPENAI_IMAGE_MODEL`, `OPENAI_IMAGE_QUALITY`,
`OPENAI_TRANSCRIBE_MODEL`, `OPENAI_VISION_MODEL`). Без ключа хаб работает как раньше. `GET /api/features`
говорит приложению, что включено.

- `generate_image` (MCP — для агентов и черновиков ИИ): Images API, картинка ложится на доску как обычная
  (файл — в хранилище хаба). Отказ модели по правилам безопасности — понятной ошибкой.
- Голос: в поле запроса ✦ ИИ кнопка микрофона (только если голос включён). Запись (MediaRecorder:
  webm/opus, на macOS — mp4) уходит на хаб `POST /api/voice`, хаб распознаёт её моделью OpenAI
  и возвращает текст в поле. Отправляет человек — распознанное можно поправить. Запись — до 90 секунд.
  Android: разрешение `RECORD_AUDIO` в манифесте (CI дописывает и проверяет в APK), запрос — системный;
  macOS: `NSMicrophoneUsageDescription` в `Info.plist`.

**Распознавание рукописного** (`server/hub/src/handwriting.ts`). Соседние штрихи (ближе 60) — группа: слово,
строка, абзац. Через минуту затишья хаб рисует новые группы картинками и отдаёт модели OpenAI пачками по 8;
ответ хранится в `handwriting/<доска>.json` по отпечатку группы (id и время штрихов) — изменилась группа,
распознаётся заново; исчезла — запись удаляется. Распознанное находится поиском (в приложении и `search`
агентов — ведёт к штриху), видно агентам в `read_board` и `fetch` разделом «Рукописное (распознано)».

**История версий** (`server/hub/src/history.ts`, `HistoryPanel.tsx`). Версия — полное состояние доски
после 2 минут затишья, не чаще раза в 10 минут; первая — когда доска впервые открылась на хабе. Хранятся
все за сутки, по одной в час — неделю, по одной в день — месяц. В приложении: «Доски» → «История» —
версии картинками (кто менял, сколько элементов), «Вернуть» (в два касания) и «Копией» (новая доска
рядом). «Вернуть» не подменяет документ, а новой правкой приводит элементы к виду версии; до и после —
версии, так что возврат можно вернуть, а удалённое им лежит в корзине. Агентам — `list_versions`,
`restore_version`.

**PDF**: фрейм страницы шире страницы на 32 с каждой стороны — его берут за поля, не попадая в страницу.

## Почему так

- Один ключ OpenAI на картинки, голос и рукописное — одна настройка у владельца; цены — копейки
  (картинка ~$0.05, минута голоса ~$0.005, группа рукописного — доли цента).
- Голос через хаб, а не распознаватель системы: одинаково на Android, macOS и Windows и лучше по-русски.
- Распознавание рукописного на хабе, а не на устройстве: один раз для всех устройств и агентов.

## Последствия

- Без ключа OpenAI: «нарисуй» — SVG от Claude, кнопки микрофона нет, рукописное не распознаётся.
- Встроенный AI-чат с ключом API — следующий шаг фазы 4.
