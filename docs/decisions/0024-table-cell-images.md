# 0024. Картинки в ячейках таблицы и высота строки

- Статус: принято
- Дата: 2026-11-10

## Контекст

В таблицу нужно класть картинки, и они должны вписываться в высоту строки.

Владелец выбрал:

- высоту каждой строки тянуть за её край;
- в ячейке может быть несколько картинок;
- картинки можно класть в любую ячейку, а не в отдельный тип колонки.

## Решение

- **Хранение.** Картинки ячейки лежат в той же строке, рядом со значением:
  - ключ `img:<id колонки>` хранит список `{asset, w, h, alt?}` целиком (`setCellImages`, `addCellImages`);
  - значение ячейки, её тип, формулы, итоги и сортировка от картинок не зависят;
  - файлы лежат в общем хранилище картинок (как у картинок доски): на устройстве в IndexedDB, на хаб уходят сами;
  - удаление колонки убирает и её картинки.
- **Высота строки** — поле строки `height`, от 40 до 800 пикселей (`setRowHeight`, `clampRowHeight`):
  - если высота не задана, строка подстраивается под текст;
  - картинка всегда равна высоте строки минус отступы (`cellImageHeight`), ширина пропорциональна;
  - у строки без заданной высоты картинка 28 пикселей.
- **Приложение** (`TableImages.tsx`, `TableView.tsx`):
  - касание ячейки показывает рядом кнопку «+ 🖼» для выбора с устройства (несколько сразу);
  - картинку можно вставить в ячейку или перетащить на неё;
  - касание картинки открывает её крупно: «Убрать из ячейки», листание, «← Назад»;
  - высоту меняют, перетаскивая номер строки (на мыши — полоску под ним): касание номера — меню строки, движение — высота;
  - в меню строки есть «По тексту», чтобы сбросить высоту;
  - всё это отменяется кнопкой отмены таблицы.
- **Хаб:**
  - миниатюра и PDF таблицы рисуют картинки в высоту строки (`tableImages`, `tablePages`);
  - markdown для агентов показывает «[картинок: N]».
- **Агенты:**
  - `read_table` json отдаёт `images` (колонка → список) и `height`;
  - `write_table` принимает `rows[].images` (список целиком: `{asset}` — оставить, `{url|data|svg}` — новая, `alt`) и `rows[].height`;
  - `get_image` с id таблицы показывает картинку ячейки по её `asset`.

## Последствия

- Список картинок ячейки — одно значение: если два устройства одновременно добавят картинки в одну ячейку, останется последняя правка.
- Ширина колонки растёт под картинки (таблица листается вбок), как и под длинный текст.
