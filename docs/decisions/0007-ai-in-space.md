# 0007. ИИ прямо в Kayospace (предложение)

- Статус: предложение — ждёт решений по вопросам в конце
- Дата: 2026-11-04

## Контекст

Сейчас ИИ работает снаружи: Claude Code подключается к хабу по MCP и правит доски. Хочется того же
изнутри приложения: выделил стикеры или рисунок → попросил → результат появился на доске,
на любом устройстве, без терминала.

## Предлагаемое решение

**ИИ живёт на хабе.** Хаб получает ключ Anthropic API (`ANTHROPIC_API_KEY` в `deploy/.env`) и новый
адрес `POST /api/ai` (ответ потоком). Устройство отправляет: доску, просьбу, выделенные элементы,
видимую область и — для рукописного — картинку выделения (рисует её само). Хаб запускает Claude
с теми же инструментами, что у MCP (`read_board`, `add_sticky`, `add_arrow`, `update_element`…),
и пишет прямо в доску: все устройства видят, как появляются элементы.

Почему так: ключ не лежит на устройствах; работает одинаково на Маке, Windows и планшете;
инструменты общие с Claude Code; правки ИИ подписаны (`createdBy: агент kayospace-ai`).

Отклонено: ключ на каждом устройстве (утечёт, три места для настройки); только Claude Code
(нужен компьютер и терминал, на планшете неудобно).

## Инструменты (по приоритету)

1. **Действия над выделением** — кнопка «✦ ИИ» в меню выделения:
   - распознать рукописное → текст (картинка выделения уходит в Claude как изображение);
   - сгруппировать стикеры по темам и разложить колонками с заголовками;
   - резюме / выводы → стикер рядом;
   - список или текст → схема (стикеры + стрелки);
   - продолжить мозговой штурм: ещё N стикеров в том же духе;
   - исправить / перевести / сократить текст.
2. **Строка запроса** (Ctrl/⌘ J): «нарисуй схему процесса найма», «разбей проект на задачи» —
   результат встаёт в свободное место на доске.
3. **Чат по доске** — панель справа: вопросы по содержимому всех досок (поиск уже есть на хабе).
4. Позже: голос → стикер, подписи к картинкам, поиск по смыслу, ИИ-«уборка» доски.

## Как это выглядит

- Пока ИИ работает — рамка «ИИ думает…» на месте будущего результата, ответ появляется по частям.
- Всё сделанное за один запрос — одним шагом: кнопка «Отменить» в плашке результата убирает
  его на всех устройствах (хаб помнит, что создал и что изменил).
- Цена каждого запроса видна в плашке (токены → рубли/доллары), есть дневной лимит.

## Вопросы

1. Ключ Anthropic API на хабе (оплата по факту, обычный запрос — доли цента) — подходит?
2. Что делать первым: распознавание рукописного, группировку стикеров или строку запроса?
3. Ответы: сразу на доску (как Miro AI) или сначала предпросмотр с кнопкой «Вставить»?
