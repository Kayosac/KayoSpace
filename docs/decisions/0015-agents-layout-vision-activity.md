# 0015. Агенты: раскладка пачкой, картинка доски, правки видны и отменяются

- Статус: принято
- Дата: 2026-11-05

## Контекст

Фаза 3: «Claude Code и ChatGPT читают доску и раскладывают стикеры». Агенты уже читали и писали доски
через MCP, но:

- стикеры добавлялись по одному, координаты агент считал сам, получалось криво и наползало на чужое;
- рукописное и рисунки агент не видел: в тексте доски есть только сводка штрихов;
- на устройстве не было видно, что сделал агент, а отменить его правки было нельзя
  (отмена там — только своих правок);
- для ChatGPT не хватало инструмента `fetch`.

## Решение

**Раскладка** (`packages/board/src/layout.ts`, `server/hub/src/mcp-layout.ts`):

- `add_elements` — до 100 стикеров и надписей за вызов. Раскладка: сетка (по умолчанию почти квадрат),
  ряд или столбец; ширина колонки — по самому широкому элементу, высота ряда — по самому высокому.
- Куда класть: `at`, `frame` (внутрь, под его содержимым, фрейм растягивается), `newFrame`
  (создать фрейм вокруг), иначе — справа от занятой области.
- `arrange_elements` раскладывает существующие элементы; `move_elements` двигает их, фрейм — с содержимым.
- Каждый вызов — одна транзакция Yjs: на устройстве это одно изменение.

**Картинка доски** — `view_board`. Вся доска, фрейм или область рисуются в SVG (`server/hub/src/render.ts`)
и переводятся в PNG через resvg (`@resvg/resvg-js`: собранный модуль, без браузера; в образе хаба —
шрифт DejaVu с кириллицей). Отрисовка упрощённая:

- штрих — линия средней толщины;
- текст переносится по оценке ширины символа;
- стрелки начинаются и заканчиваются у краёв элементов;
- картинки — из хранилища хаба (до 12 МБ на снимок).

Вместе с картинкой агент получает её соответствие координатам доски.

**Инструкции сервера MCP** (`agent-guide.ts`) клиент показывает модели при подключении: координаты,
размеры, каким инструментом что делать, просьба не трогать чужое.

**ChatGPT.** `search` отдаёт `{ results: [{ id, title, url, … }] }`, `fetch` по id отдаёт доску в markdown.
`url` — ссылка `kayospace://board/<id>?element=<id>`: приложение открывает доску и показывает элемент.
Вход — тот же OAuth с динамической регистрацией клиента и refresh-токенами.

**Кто писал.** Имя агента в `updatedBy`:

- приложение OAuth — по названию клиента («Claude», «ChatGPT»);
- иначе — по User-Agent (`claude-code`);
- иначе — `mcp`.

Хаб передаёт имя в обработчики через `AsyncLocalStorage`, потому что сервер MCP создаётся на каждый запрос.

**Правки агента на устройстве** (`packages/canvas/src/agent-activity.ts`):

- Агентская транзакция — чужая и со свежим элементом от агента. Её удаления тоже относятся к агенту.
- Подряд идущие вызовы одного агента (пауза меньше 10 с) — одна пачка.
- Для каждого элемента пачки запоминается, каким он был до неё и стал после.

Плашка «Claude Code добавил 4 · Показать · Отменить»:

- «Показать» — вид на эти элементы и подсветка на 5 секунд;
- «Отменить» — элементы возвращаются к виду до пачки одной своей правкой. Её можно отменить кнопкой
  «Отменить» на панели. Элементы, которые после агента правил человек, не трогаются.

## Последствия

- Картинка доски для агента — приблизительная (без нажима пера, своя вёрстка текста); для чтения
  моделью хватает, для печати — экспорт в приложении.
- Отменить пачку можно, пока открыта доска и не пришла следующая пачка; дальше — резервные копии.
- На тарифе Pro ChatGPT в режиме разработчика запись может быть недоступна — это ограничение OpenAI.
