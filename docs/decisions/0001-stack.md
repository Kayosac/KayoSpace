# 0001. Стек: веб-ядро в Tauri 2, свой движок холста, Yjs

- Статус: принято
- Дата: 2026-11-04

## Контекст

Нужен один инструмент для macOS, Windows и Android со стилусом, офлайном, синхронизацией и доступом агентов.
Разработчик один, код пишет в основном Claude Code. Инструмент для себя, на годы.

## Решение

- **Оболочка:** Tauri 2 поверх веб-ядра на TypeScript. Сначала итерации в браузере, затем та же сборка в Tauri.
- **Холст:** свой движок на открытых примитивах. tldraw отклонён из-за лицензии (без ключа в продакшене редактор
  перестаёт рисоваться), Excalidraw — из-за эстетики и модели, которую трудно расширить под документы и задачи.
- **Данные:** Yjs (CRDT), одна доска — один документ, локальное хранилище на каждом устройстве.
- **Хаб:** Node + Hono + Hocuspocus + SQLite на своём VPS; он же MCP-сервер для агентов.

## Последствия

- Плюс 4–6 недель на старте за счёт своего движка — в обмен на контроль над задержкой пера и моделью данных.
- Главный риск — задержка пера в Android WebView. Проверяется в фазе 0 (Pen Lab). Запасной путь — нативный слой
  рисования на Kotlin поверх WebView.
- ChatGPT подключается только к удалённому HTTPS-серверу, поэтому хаб нужен для агентов в любом случае.
