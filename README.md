# Kayospace

Личный воркспейс: бесконечный холст, стилус, проекты и доступ для агентов (Claude Code, ChatGPT) через MCP.
Платформы: macOS, Windows, Android.

Сейчас идёт **фаза 1**: основной холст. Полный план — [docs/PLAN.md](docs/PLAN.md).

## Что внутри

```
apps/
  workspace/    основное приложение: бесконечный холст (React + свой движок)
  pen-lab/      стенд замера пера (веб, Vite)
  app/          оболочка Tauri 2 для macOS, Windows, Android (показывает workspace)
packages/
  model/        типы элементов холста, бинарный формат штрихов
  ink/          ввод пера (Pointer Events), отрисовка штрихов, статистика задержки
  board/        доска на Yjs: элементы, изменения, экспорт в Markdown/JSON для агентов
  sync/         протокол синхронизации и клиент (браузер и Node)
  canvas/       движок холста: камера, сцена, отрисовка, навигация, инструменты
server/
  hub/          хаб: синхронизация досок, хранение на диске, MCP для агентов
e2e/            проверки в настоящем браузере (Playwright) вместе с хабом
docs/           план, решения (ADR), инструкции
```

## Быстрый старт на Маке

Нужно: Node 22+, pnpm, для приложения — Rust и Xcode Command Line Tools.

```bash
# один раз
corepack enable                 # включает pnpm, версия берётся из package.json
xcode-select --install          # если ещё не стоит
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# в папке проекта
pnpm install
pnpm test                       # тесты пакетов
pnpm dev                        # приложение + локальный хаб, уже подключены: http://localhost:5180
pnpm pen-lab                    # Pen Lab: http://localhost:5173
```

### Pen Lab на планшете без сборки приложения

```bash
pnpm pen-lab:lan                # дев-сервер Pen Lab доступен в локальной сети
```

Откройте на планшете `http://<IP-мака>:5173`. По HTTP без TLS браузер не даёт «сырые события» (pointerrawupdate) —
это нормально, их проверим в приложении. Ещё проще — опубликованная страница Pen Lab из чата: она открывается по HTTPS.

### Приложение для macOS

```bash
pnpm app:dev                    # окно Tauri с горячей перезагрузкой
pnpm app:build                  # .app и .dmg в apps/app/src-tauri/target/release/bundle
```

### Приложение для Android

1. Поставьте Android Studio, в SDK Manager — Android SDK, NDK (Side by side), Command-line Tools.
2. Пропишите переменные окружения (например, в `~/.zshrc`):
   ```bash
   export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
   export ANDROID_HOME="$HOME/Library/Android/sdk"
   export NDK_HOME="$ANDROID_HOME/ndk/$(ls -1 $ANDROID_HOME/ndk | tail -1)"
   ```
3. Добавьте Rust-цели:
   ```bash
   rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
   ```
4. Сгенерируйте Android-проект и иконки:
   ```bash
   pnpm app:android:init
   pnpm --filter @kayospace/app icons
   ```
5. Включите на планшете «Отладку по USB», подключите кабелем и запустите:
   ```bash
   pnpm app:android:dev            # приложение на планшете с горячей перезагрузкой
   pnpm app:android:build          # APK в apps/app/src-tauri/gen/android/app/build/outputs/apk
   ```

### Приложение для Windows

На Windows-машине: Node 22, pnpm, Rust, «Desktop development with C++» из Visual Studio Build Tools
(WebView2 уже есть в Windows 10/11). Затем `pnpm install` и `pnpm app:build`.

## Что умеет холст

- Перо (ручка с нажимом, выделитель), ластик частями, стикеры, текст, фигуры, стрелки с привязкой, картинки.
- Фреймы (F): именованные области; перенос за заголовок везёт содержимое; список фреймов — в панели досок.
  Цвет подложки — у выделенного фрейма («По теме» или свой, одинаковый в светлой и тёмной теме).
- Выделение рамкой и лассо: перенос, масштаб, поворот, копия; «⋯» — порядок слоёв и выравнивание.
- Картинка с доски — в буфер обмена самим файлом (Ctrl/⌘ C или «Копировать»): вставляется в любую программу;
  остальное копируется элементами Kayospace, как раньше.
- Доски и проекты: Ctrl/⌘ K — найти, создать, переключить; проекты — чипы в панели досок.
- Экспорт: PNG доски, фрейма или выделенного; PDF — по странице на фрейм.
- Презентация по фреймам («Показать» в панели досок или F5): касание справа — дальше, слева — назад.
- PDF на доску (кнопка картинок, перетаскивание, «Поделиться» на Android): страницы во фреймах — пишите поверх пером.
- Шаблоны новых досок («+ Доска»): пустой, неделя, ретро, мозговой штурм, встреча.
- Корзина — своя панель: удалённое за 7 дней (и доски целиком) возвращается одним касанием.
- ✦ ИИ (Ctrl/⌘ J): «вставь картинку … сюда» — ИИ найдёт её в интернете; «нарисуй …» — нарисует
  (OpenAI, если на хабе есть ключ, иначе схемой SVG); микрофон — сказать просьбу голосом (с ключом OpenAI).
- История доски («Доски» → «История»): версии картинками, «Вернуть» и «Копией».
- Задачи: выделите стикер → «Задача» — статус, срок, важность прямо на стикере; панель «Задачи» — со всех досок.
- Чат с ИИ (кнопка на панели): разговор на доске, помощник помнит прошлые реплики, правки — предпросмотром.
  Смотрит на то, что видно на экране или выделено; всю доску — когда попросите.
- Канбан задач («Задачи» → «Канбан»): колонки по статусам, карточки перетаскиваются пальцем или пером.
- Документы («Доски» → «Новый документ»): заголовки, списки, чек-листы, цитаты, таблицы — кнопками; «Фрагмент доски»
  вставляет фрейм картинкой, касание открывает доску. `.md` открывается документом (кнопкой «Картинка, PDF или .md»,
  перетаскиванием, «Поделиться» на Android), документ сохраняется в `.md`.
- Таблицы («Доски» → «Новая таблица»): колонки с типами — текст, число, флажок, дата, выбор, ссылка, формула
  (`[Цена] * [Кол]`, ЕСЛИ, ОКРУГЛ, СУММ, ДНИ…); итоги внизу, сортировка и поиск. Картинки — в любую ячейку
  («+ 🖼», вставка, перетаскивание), вписываются в высоту строки; её тянут за номер строки. Таблица — на весь
  экран: масштаб (−/+, Ctrl/⌘ + колёсико, щипок), «⤢ Подогнать» — размеры под содержимое, ширина колонки —
  за край заголовка; Enter и ↑↓ — по ячейкам.
- Артефакты из Claude: в чате скажите «на доску» — страница, рисунок, схема или код лягут карточкой и откроются
  касанием живыми; «В Claude» — забрать документ, таблицу или артефакт обратно в чат, «обнови на доске» — вернуть.
- Документ или таблица на доске — карточкой с миниатюрой (кнопка «Документ или таблица» на панели):
  касание открывает её поверх. Помощник читает документы, карточки которых видны или выделены.
- Надпись рамкой: инструментом «Текст» протяните рамку — шрифт подберётся под неё; угол тянется свободно.
- Фигуры (список вверх от кнопки «Фигуры»): прямоугольники, эллипс, треугольник, ромб, шестиугольник,
  звезда, блок-стрелка, выноска, линия, стрелка; заливка — отдельным цветом; у выделенных — цвет, заливка, толщина.
- Экспорт и удаление — иконками у каждого пункта списка досок; документы и таблицы — в PDF, документ — ещё и в `.md`,
  артефакт — исходником.
- Рукописное распознаётся (с ключом OpenAI на хабе): находится поиском, агенты его читают.
- Мини-карта в правом верхнем углу; поворот холста двумя пальцами.
- Доска на 20 000 объектов листается и масштабируется на 60 кадрах (замер — `pnpm e2e:bench`).

## Хаб: синхронизация и агенты

```bash
pnpm hub
```

Хаб печатает адреса: MCP для агентов, адрес для планшета в локальной сети и готовую команду для Claude Code.
Доски хранятся в `server/hub/data/`.

**Claude Code.** Подключите один раз:

```bash
claude mcp add --transport http kayospace http://localhost:4000/mcp
```

Дальше можно просить: «прочитай доску pen-lab», «добавь на доску plan стикеры с задачами на неделю»,
«найди на досках всё про шрифты», «нарисуй схему: стикеры этапов и стрелки между ними».
Инструменты: `list_boards`, `read_board`, `view_board` (картинка доски — агент видит рукописное),
`search`, `fetch`, `add_elements` (пачкой с раскладкой сеткой, рядом, столбцом, во фрейм), `arrange_elements`,
`move_elements`, `add_sticky`, `add_text`, `add_shape`, `add_arrow`, `add_frame`, `update_element`,
`delete_elements`; картинки — `add_images` (по ссылке, файлом или SVG), `add_image_file` (из чата ChatGPT), `generate_image`
(OpenAI), `get_image`; история — `list_versions`, `restore_version`; задачи — `list_tasks`, `update_task`; документы — `read_page`, `write_page` (и правка раздела); таблицы — `read_table`, `write_table`; артефакты — `save_artifact`, `read_artifact`; карточка на доске — `place_doc`; корзина — `list_trash`,
`restore_elements`; что нового — `get_changes`; проекты и доски — `list_projects`, `create_project`,
`create_board`, `move_board`, `delete_board`, `list_deleted_boards`, `restore_board`.
Что агент изменил, видно на устройстве — и отменяется одним нажатием (решение 0015); удалённое 7 дней лежит
в корзине (решение 0016).
MCP-эндпоинт принимает запросы только с этого компьютера.

**Подключить устройство** — по коду, без токенов (решение 0008). На подключённом устройстве: Настройки →
Устройства → «+ Добавить» — появятся QR и 6-значный код (одноразовый, 5 минут). На новом устройстве наведите
камеру на QR или в «Подключение к хабу» введите адрес хаба и код. Самое первое устройство — `pnpm pair`
(на сервере — `docker compose exec hub pnpm pair`) печатает QR и код прямо в терминале. Там же, в
«Устройствах», — список с последним входом и «Отключить».

**Разработка.** `pnpm dev` сам поднимает хаб на `127.0.0.1:4000` (данные в `.dev-hub/`, без токена,
из сети не виден) и сразу подключает к нему приложение. В собранных версиях этого режима нет.

**Приложение Claude** (claude.ai, телефон, компьютер) подключает Kayospace как свой коннектор — нужен хаб
на VPS с HTTPS: Настройки → Коннекторы → «Добавить свой коннектор» → URL `https://<хаб>/mcp` → вход
на странице хаба по ключу администратора (`HUB_TOKEN`). Так же подключается **ChatGPT** (режим разработчика). Подробно — [deploy/README.md](deploy/README.md#3-подключение-устройств).

**ИИ в доске.** Кнопка «✦ ИИ» в меню выделения (распознать рукописное, резюме, сгруппировать, схема, ещё идей,
исправить, сократить, перевести) и свой запрос — Ctrl/⌘ J. Результат сначала виден предпросмотром,
в доску попадает по «Вставить» (и отменяется одним шагом). Работает на подписке Claude через Claude Code —
исполнитель на сервере или на компьютере (`pnpm ai-worker`), см. [deploy/README.md](deploy/README.md#4-ии-в-доске-кнопка--ии).

## Хаб на VPS

Чтобы устройства синхронизировались из любой сети, хаб ставится на VPS одной командой — с HTTPS, свой домен
не нужен. В конце установки скрипт печатает QR для первого устройства. Подробно — [deploy/README.md](deploy/README.md):

```bash
curl -fsSL https://raw.githubusercontent.com/Kayosac/KayoSpace/main/deploy/setup.sh | sudo bash
```

## CI и готовые сборки

- **CI** (`.github/workflows/ci.yml`) — на каждый пуш в `main` и пулл-реквест: типы, линтер, тесты, сборка Pen Lab.
- **Сборка приложения** (`.github/workflows/app.yml`) — вручную: Actions → «Сборка приложения» → Run workflow
  (можно выбрать платформы) или пушем тега `v*`. Результаты — во вкладке Artifacts у запуска:
  - `kayospace-android-apk` — debug-APK для планшета (ARM64): распаковать zip, перекинуть APK на планшет и установить
    (разрешите установку из неизвестных источников);
  - `kayospace-macos` — `.dmg` (без подписи: при первом запуске — правый клик → «Открыть»);
  - `kayospace-windows` — установщики `.msi` и `.exe`.

Пока в репозитории нет `pnpm-lock.yaml`, CI ставит зависимости без него. После первого `pnpm install` закоммитьте
lock-файл — CI сам перейдёт на `--frozen-lockfile`.

## Команды

| Команда                                           | Что делает                                              |
| ------------------------------------------------- | ------------------------------------------------------- |
| `pnpm dev`                                        | Приложение + локальный хаб (http://localhost:5180)      |
| `pnpm dev:lan`                                    | Только приложение, доступно в локальной сети            |
| `pnpm pair`                                       | QR и код подключения устройства к запущенному хабу      |
| `pnpm pen-lab`                                    | Pen Lab в браузере (http://localhost:5173)              |
| `pnpm e2e`                                        | Проверки в браузере вместе с хабом (Playwright)         |
| `pnpm e2e:dev`                                    | Проверка режима разработки (`pnpm dev`)                 |
| `pnpm e2e:bench`                                  | Замер скорости на доске из 20 000 объектов              |
| `pnpm test`                                       | Тесты всех пакетов (Vitest)                             |
| `pnpm typecheck`                                  | Проверка типов                                          |
| `pnpm lint` / `pnpm format`                       | ESLint / Prettier                                       |
| `pnpm --filter @kayospace/pen-lab build:single`   | Pen Lab одним HTML-файлом в `apps/pen-lab/dist-single/` |
| `pnpm app:dev` / `pnpm app:build`                 | Приложение для текущей ОС                               |
| `pnpm app:android:dev` / `pnpm app:android:build` | Приложение для Android                                  |
