# Kayospace — правила для Claude Code

Личный воркспейс: бесконечный холст со стилусом, проекты, доступ агентов через MCP. Платформы: macOS, Windows, Android.
Полный план и решения: `docs/PLAN.md`, `docs/decisions/`. Текущая фаза — **4 (удобство и AI)**, шаги — в `docs/PLAN.md`.

## Стек

- TypeScript (strict), монорепо pnpm + Turborepo.
- UI: Vite; основное приложение — React 19 (без плагина, TSX через esbuild), Pen Lab — чистый TS.
- Холст: **свой движок** (решение 0001). Внешние движки холста (tldraw, Excalidraw) не подключаем.
- Штрихи: свой алгоритм в `packages/ink/src/render.ts` (решение 0002).
- Данные: Yjs (CRDT), локально — IndexedDB (`y-indexeddb`); синхронизация — свой протокол поверх WebSocket (`packages/sync`, решение 0004).
- Оболочка: Tauri 2 (`apps/app`).
- Агенты: MCP TypeScript SDK v2 (`@modelcontextprotocol/server`), Streamable HTTP на `/mcp` хаба.

## Структура

- `packages/model` — типы элементов и форматы данных. Без зависимостей от DOM.
- `packages/ink` — ввод пера, отрисовка штрихов, метрики. Зависит только от `model`.
- `packages/board` — доска на Yjs: элементы, изменения, экспорт для агентов, шаблоны досок (`templates.ts`).
- `packages/sync` — протокол синхронизации и клиент (браузер и Node).
- `packages/canvas` — движок холста без React: камера, сцена, отрисовка, навигация, инструменты (решение 0006);
  упрощённая отрисовка при отдалении, фреймы, экспорт PNG/PDF (решение 0009).
- `server/hub` — хаб: WebSocket-синк, хранение досок на диске, REST, MCP, OAuth для коннектора Claude,
  очередь задач ИИ и исполнитель (`pnpm ai-worker` — Claude Code на подписке, решение 0007),
  устройства и коды подключения (`devices.ts`, `pnpm pair` — решение 0008), резервные копии (`backups.ts` — решение 0010);
  для агентов — раскладка (`mcp-layout.ts`), картинка доски (`render.ts`), инструкции (`agent-guide.ts`) — решение 0015;
  корзина (`trash.ts`), удалённые доски (`deleted-boards.ts`), картинки (`images.ts`, `mcp-images.ts`),
  изменения и проекты (`mcp-extra.ts`) — решение 0016.
- `apps/pen-lab` — стенд замера пера; умеет синхронизировать штрихи через хаб.
- `apps/workspace` — основное приложение: холст, панель инструментов, настройки, доска в IndexedDB + синк;
  корзина (`TrashPanel.tsx`), презентация (`Presentation.tsx`), импорт PDF (`pdf-import.ts`, pdf.js) — решение 0017.
- `apps/app` — Tauri-оболочка; фронтенд берёт из `apps/workspace/dist`. Плагины: deep-link (`kayospace://`),
  single-instance, barcode-scanner (Android), свои `plugins/secure-store` (токен устройства в хранилище ОС)
  и `plugins/share-target` («Поделиться» в Android → доска «Входящие»).
- `e2e` — проверки в настоящем браузере (Playwright) вместе с хабом; скриншоты из CI — в ветке `ci-previews`.

## Команды

- `pnpm install`, `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm format`
- `pnpm dev` — приложение на http://localhost:5180 вместе с локальным хабом на 127.0.0.1:4000 (подключено само);
  `pnpm pen-lab` — Pen Lab на http://localhost:5173
- `pnpm e2e` — собрать приложения и прогнать проверки в браузере (нужен `pnpm exec playwright install chromium` в `e2e`);
  `pnpm e2e:bench` — замер скорости на доске из 20 000 объектов (стенд `apps/workspace/bench.html`)
- `pnpm hub` — хаб на http://localhost:4000 (MCP: `/mcp`, синк: `/sync/<доска>`); `pnpm pair` — QR и код
  подключения устройства; `pnpm e2e:dev` — проверка режима разработки
- `pnpm app:dev`, `pnpm app:android:dev` — приложение
- Выпуск версии: одна версия в `apps/workspace`, `apps/app`, `tauri.conf.json`, `Cargo.toml` (проверяет тест),
  затем тег `vX.Y.Z` или запуск «Сборка приложения» с полем `release: vX.Y.Z` — CI соберёт, подпишет
  и опубликует релиз с `latest.json` (автообновление, решение 0011); тег должен совпадать с версией
- Версии Rust-зависимостей закреплены в `apps/app/src-tauri/Cargo.lock`; обновлять — отдельным изменением
  (`cargo update`) с проверочной сборкой всех платформ. Сборки быстрые за счёт кэша с main (решение 0013)

## Соглашения

- Идентификаторы и имена файлов — по-английски; комментарии, тексты интерфейса, сообщения об ошибках — по-русски.
- Пакеты экспортируют исходники TS напрямую (`main: ./src/index.ts`), отдельной сборки пакетов нет.
- Новая зависимость — только если она делает существенную работу; крупные решения записываем в `docs/decisions/NNNN-*.md`.
- Тесты рядом с кодом: `*.test.ts`, Vitest. Геометрию и форматы данных покрываем тестами обязательно.
- Цвета в UI — только через CSS-переменные; у каждой страницы есть светлая и тёмная тема.
- Токены устройств — только в хранилище секретов (`apps/workspace/src/secrets.ts`), не в настройках и не в логах.
  `HUB_TOKEN` — ключ администратора; устройствам он не нужен.
- Режим разработки (`DEV_HUB` в `config.ts`) не должен попадать в сборку — это проверяет `build.test.ts`.

## Сенсор прежде всего (Android-планшет без клавиатуры)

- Любое действие доступно касанием: у каждого поля есть кнопка («Создать», «Готово») или оно сохраняет само.
  Enter, Escape и сочетания клавиш — только ускорители, никогда не единственный путь.
- Поля названий — `CommitInput`: сохраняет при уходе фокуса, по «Готово» и при закрытии панели. Уход фокуса
  ничего не отменяет — на планшете клавиатуру прячут, не закончив ввод.
- Касание холста снимает фокус с полей панелей (`releaseFieldFocus`), иначе холст «съедает» blur.
- Фокус в поле сами ставим только при мыши (`finePointer()`), иначе на планшете вылезает клавиатура.
- Цели для пальца — не меньше 40 пикселей, шрифт полей — 16 пикселей (`@media (pointer: coarse)`);
  подсказки про клавиши на сенсоре скрыты.
- Новый интерфейс проверяем e2e-тестом «планшет без клавиатуры»: только `tap()` и `fill()`, без `press()`.

## Правила для кода пера и холста

- Горячий путь (pointermove → отрисовка) не аллоцирует лишнего и не трогает DOM-раскладку.
- Всегда читаем `getCoalescedEvents()`; предсказанные точки (`getPredictedEvents()`) рисуем только во временном хвосте.
- Построение штриха причинное: уже выпущенные сэмплы не меняются — это позволяет дорисовывать штрих по кускам.
- Законченный штрих хранится как исходные точки (`encodeStroke`), а не как контур: контур всегда можно пересчитать.
- Толщина пера — в экранных пикселях; штрих хранит `unit = 1 / zoom`, чтобы контур пересчитывался одинаково везде.
- Отменяются только свои правки: всё, что делает пользователь, пишется с origin `LOCAL_ORIGIN`.
- ИИ пишет только в черновик (копию доски на хабе); в доску правки переносит устройство по «Вставить» — одним шагом отмены.
- Агенты по MCP пишут прямо в доску: каждый вызов инструмента — одна транзакция; устройство показывает пачку правок
  агента и отменяет её одной своей правкой (`AgentTracker`).
- Вид может быть повёрнут: экранные координаты переводим только через `screenToWorld`/`worldToScreen`, не вручную.
- Любое изменение отрисовки проверяем в Pen Lab на реальном планшете и сравниваем отчёт с предыдущим.
- Изменения отрисовки и сцены прогоняем через `pnpm e2e:bench`: сдвиг и зум — 60 кадров/с на 20 000 объектах.
- Готовую картинку сдвигаем только на целые пиксели устройства (`Renderer.moveTo`); дорисовка — при камере картинки.
- Перерисовка — только изменившихся участков; сдвиг камеры копирует готовую картинку (`Renderer.moveTo`).
  Полная перерисовка (`invalidateAll`) — только когда без неё нельзя.
- Фреймы — в слое ниже всех (z с префиксом `!`); перенос, копия и удаление фрейма — вместе с содержимым.
- Удалённая доска — отметка в воркспейсе (`markBoardDeleted`), не стирание: 7 дней её можно вернуть.
  Для агентов удалённых досок нет (`BoardStore.live()`). Хаб скачивает картинки по ссылкам только через
  `fetchImage` (защита от SSRF).
