# Хаб Kayospace на VPS

Хаб в интернете: планшет, мак и Windows синхронизируются через него из любой сети, Claude Code подключается
по MCP. Устройства подключаются по одноразовому коду и получают свои токены; `HUB_TOKEN` — ключ
администратора. Соединение — по HTTPS (сертификат Let's Encrypt получает Caddy).
Свой домен не обязателен: используется адрес вида `203-0-113-5.sslip.io`, который сам указывает на IP сервера.

## 1. Сервер

Подойдёт любой VPS:

- Ubuntu 24.04 или 22.04 (Debian 12 тоже подойдёт);
- 1 ГБ памяти и больше, 10 ГБ диска;
- публичный IPv4-адрес;
- открытые входящие порты 80 и 443 (если у провайдера есть свой файрвол в панели — откройте их там).

Если порт 443 уже занят (например, VPN на Xray), скрипт его не тронет: хаб будет работать по HTTPS на порту
8443 (или 9443, 10443 — первом свободном). Порт 80 нужен свободным — через него выдаётся сертификат.
Тогда адрес хаба для устройств — `https://<домен>:8443`, скрипт напечатает его целиком.

## 2. Установка — одна команда

Подключитесь к серверу по SSH (провайдер даст IP и пароль или ключ):

```bash
ssh root@<IP-сервера>
```

и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/Kayosac/KayoSpace/main/deploy/setup.sh | sudo bash
```

Скрипт сам: поставит Docker, скачает код в `/opt/kayospace`, придумает ключ администратора и адрес
`<IP>.sslip.io`, соберёт и запустит хаб с HTTPS, дождётся сертификата, напечатает всё нужное для подключения
и в конце — QR и код для первого устройства:

```
Готово. Хаб работает: https://203-0-113-5.sslip.io

  Адрес хаба:  203-0-113-5.sslip.io
  Ключ администратора (HUB_TOKEN): 4f1c…
  …

Подключите первое устройство
  ▀▀▀ (QR) ▀▀▀
  Адрес хаба:  https://203-0-113-5.sslip.io
  Код:         482 913   (одноразовый, действует 5 мин)
```

Сохраните ключ администратора: он нужен коннектору Claude, Claude Code и чтобы вернуть доступ, если отключены
все устройства. Посмотреть его снова: `cat /opt/kayospace/deploy/.env`.

Свой домен вместо sslip.io: направьте A-запись домена на IP сервера и перед первой установкой задайте
`HUB_DOMAIN`:

```bash
curl -fsSL https://raw.githubusercontent.com/Kayosac/KayoSpace/main/deploy/setup.sh | sudo HUB_DOMAIN=hub.example.com bash
```

## 3. Подключение устройств

**Планшет, мак, Windows (приложение):**

- Первое устройство: наведите камеру на QR из вывода скрипта (или откройте приложение → «Подключение к хабу»
  и введите адрес хаба и 6 цифр). Код истёк — `cd /opt/kayospace/deploy && docker compose exec hub pnpm pair`.
- Следующие: на подключённом устройстве Настройки → Устройства → «+ Добавить» — QR и код на 5 минут.
- Там же список устройств с последним входом; «Отключить» сразу отзывает токен этого устройства.
- Токен устройства хранится в хранилище ОС (Keychain, Credential Manager, Android Keystore), вводить его не нужно.
- Устройства со старыми настройками (адрес + `HUB_TOKEN`) после обновления сами переходят на свой токен.

**Pen Lab** по-прежнему подключается адресом и `HUB_TOKEN` (Настройки → Синхронизация).

**Claude Code:** выполните на своём компьютере команду `claude mcp add …` из вывода скрипта, затем в любой
папке запустите `claude` и попросите, например, «прочитай доску pen-lab через kayospace».

**Приложение Claude (claude.ai, телефон, компьютер) — коннектор.** Хаб умеет вход по OAuth, поэтому
Kayospace подключается как свой коннектор, и доски доступны в Claude с любого устройства:

1. claude.ai → Настройки → Коннекторы → «Добавить свой коннектор».
2. Название — `Kayospace`, URL — `https://<домен>:<порт>/mcp` (тот же адрес хаба плюс `/mcp`).
3. «Подключить» → откроется страница хаба «Подключить Kayospace» → вставьте ключ администратора
   (`HUB_TOKEN`) → «Разрешить».
4. Коннектор появится и в приложениях на телефоне и компьютере (тот же аккаунт).

**ChatGPT — коннектор (режим разработчика).** Тот же адрес и тот же вход по OAuth. Названия пунктов меню
у OpenAI меняются от выпуска к выпуску — ориентир такой:

1. chatgpt.com (в браузере; в мобильном приложении свои коннекторы пока не работают) → Settings →
   включить **Developer mode** (раздел Apps & Connectors → Advanced settings или Security).
   В рабочем пространстве Business/Enterprise его сначала включает администратор.
2. Там же — создать приложение (**Create** / «+»): название `Kayospace`, URL `https://<домен>:<порт>/mcp`,
   аутентификация — **OAuth**.
3. ChatGPT найдёт инструменты (Scan Tools) и откроет страницу хаба «Подключить Kayospace» → ключ
   администратора (`HUB_TOKEN`) → «Разрешить».
4. В чате: в меню инструментов у поля ввода выберите режим разработчика и Kayospace.

Чтение (`list_boards`, `read_board`, `view_board`, `get_image`, `search`, `fetch`, `get_changes`, `list_trash`…)
помечено как безопасное, ChatGPT
выполняет его без вопросов; на запись по умолчанию спрашивает подтверждение. Запись через свои коннекторы
OpenAI гарантирует на Business/Enterprise/Edu; на Plus/Pro, по их же справке, может быть только чтение —
проверьте в своём аккаунте.

**После обновления хаба** у агентов появляются новые инструменты, но клиенты запоминают список при
подключении: ChatGPT — [chatgpt.com/plugins](https://chatgpt.com/plugins) → Kayospace → **Refresh**, затем новый
чат; Claude — новый чат (список подтягивается сам), Claude Code — перезапуск сессии.

Правки агентов видны на устройстве: плашка «Claude добавил 6 · Показать · Отменить» — отмена одним
нажатием (решение 0015).

Доступ коннектора отзывается сменой ключа администратора (см. «Обслуживание»).

## 4. ИИ в доске (кнопка «✦ ИИ»)

ИИ работает на вашей подписке Claude через официальный Claude Code (решение 0007) — без оплаты по API.
Задачи с устройств встают в очередь на хабе, их выполняет **исполнитель**: Claude Code на сервере
или на вашем компьютере. Нужен хотя бы один.

**Исполнитель на сервере** (работает всегда, даже когда компьютер выключен):

1. На своём компьютере (где Claude Code уже вошёл в аккаунт): `claude setup-token` — выдаст длинный токен.
2. На сервере допишите в `/opt/kayospace/deploy/.env`:
   ```
   COMPOSE_PROFILES=ai
   CLAUDE_CODE_OAUTH_TOKEN=<токен из шага 1>
   ```
3. `cd /opt/kayospace/deploy && docker compose up -d --build`
4. Проверка: `docker compose logs -f ai-worker` — строка «на связи с хабом, жду задачи».

Исполнителю нужно ~1 ГБ памяти (лимит — `AI_WORKER_MEMORY` в `.env`). Задачи выполняются по одной.

**Исполнитель на Маке или Windows** (Claude Code установлен и вошёл в аккаунт), в папке проекта:

```bash
HUB_URL=https://<домен>:<порт> HUB_TOKEN=<токен хаба> pnpm ai-worker
```

На Windows (PowerShell): `$env:HUB_URL="https://…"; $env:HUB_TOKEN="…"; pnpm ai-worker`.

### OpenAI: «нарисуй», голос и рукописное (решение 0018)

С ключом OpenAI API на хабе ИИ в приложении рисует картинки моделью OpenAI (как ChatGPT), у поля запроса
появляется микрофон, а написанное пером распознаётся (поиск и агенты его видят). Подписка ChatGPT для этого
не подходит — нужен ключ API с балансом. Ключ живёт только на сервере.

1. platform.openai.com → войти → **Billing** → пополнить баланс (от $5).
2. **API keys** → **Create new secret key** → скопировать (начинается с `sk-`).
3. На сервере:
   ```bash
   cd /opt/kayospace/deploy
   echo 'OPENAI_API_KEY=sk-…' >> .env
   docker compose up -d
   ```
4. Проверка: `docker compose logs hub | grep OpenAI` — строка «OpenAI: картинки (…) и голос — включены».
   Приложение подхватит это само — когда вы в него вернётесь или перезапустите.

Цены примерно: картинка — $0.05, минута голоса — $0.005, группа рукописного — доли цента.
**Лимиты на сутки** (картинки 30, голос 100, рукописное 500) и выключатель рукописного — в приложении:
Настройки → OpenAI; сверх лимита хаб в OpenAI не ходит. Ещё надёжнее — пополнять баланс без автопополнения.
Модели можно сменить в `.env`: `OPENAI_IMAGE_MODEL`, `OPENAI_IMAGE_QUALITY` (`low`/`medium`/`high`),
`OPENAI_TRANSCRIBE_MODEL`, `OPENAI_VISION_MODEL`. Выключить — убрать строку `OPENAI_API_KEY` и `docker compose up -d`.

## Обслуживание

| Что                         | Команда на сервере                                                                                                     |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Обновления                  | сами: хаб переходит на новый релиз в течение 10 минут, при сбое откатывается (`journalctl -u kayospace-update`)        |
| Обновить прямо сейчас       | `systemctl start kayospace-update` (или повторить команду установки)                                                   |
| Выключить автообновление    | `systemctl disable --now kayospace-update.timer`                                                                       |
| Логи                        | `cd /opt/kayospace/deploy && docker compose logs -f hub` (исполнитель ИИ — `logs -f ai-worker`)                        |
| Перезапуск                  | `cd /opt/kayospace/deploy && docker compose restart`                                                                   |
| Остановить                  | `cd /opt/kayospace/deploy && docker compose down`                                                                      |
| Копия всех данных хаба      | `docker run --rm -v kayospace_hub-data:/data -v "$PWD":/backup alpine tar czf /backup/kayospace-boards.tgz -C /data .` |
| Подключить устройство       | `cd /opt/kayospace/deploy && docker compose exec hub pnpm pair` — QR и код в терминале                                 |
| Сменить ключ администратора | изменить `HUB_TOKEN` в `/opt/kayospace/deploy/.env`, затем `docker compose up -d` (токены устройств остаются)          |

## Резервные копии

Хаб сам снимает копию досок раз в 6 часов, если что-то изменилось (`BACKUP_INTERVAL_HOURS` в `.env`, 0 — выключить).
Хранятся все копии за двое суток, по одной в день — две недели, по одной в неделю — два месяца; лежат в томе
данных, в папке `backups/`. Восстановить доску: в приложении — Настройки → Резервные копии → «Восстановить доску».
Восстановленная доска появляется рядом с исходной («… (копия от 5 ноября)»), исходная не меняется.

Копии на том же диске спасают от ошибок и случайного удаления, но не от потери сервера. Для этого — снимки
диска у хостинга или время от времени скачивайте архив данных (команда «Копия всех данных хаба» выше)
и забирайте его к себе: `scp root@<сервер>:/opt/kayospace/deploy/kayospace-boards.tgz .`
